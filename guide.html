Get started

  1. Open the task board and enter the workspace password shared with you privately by the team. The password is not listed in this guide.
  2. Enter your own name in Your name. Your name and actions will be visible to teammates.
  3. Choose a category or use search, status, owner and Organizer only filters. On a phone, swipe the category navigation horizontally.
  4. Click a task title to read its deadline, deliverables and completion guidance before making changes.

Update a task

Inside a task, choose a Status, select an Owner, set an optional Internal target date, and add Notes. Click Save changes and wait for confirmation.

  • To do: not started. In progress: being worked on. Blocked: waiting for something. Done: the task’s deliverable is complete.
  • The checkbox immediately saves the task as Done. Unchecking it sets the task back to To do.
  • An internal target date does not change the organizer’s submission deadline.
  • Organizer labels identify organizer requirements. Completion guidance may also include internal suggestions.

Saving or uploading here does not email the organizer, submit your materials, or update Notion. Follow the submission instructions inside the relevant task.

Save & move progress

Shared team progress

Wait for Saved to GitHub before closing a task. Teammates can click Refresh to load your changes; the board also refreshes about once a minute while visible and no task is being edited. Sign in on another device to use the same shared records.

Export progress downloads an encrypted JSON backup of the current task records. It does not include attachment bytes; download those separately. Shared mode does not allow a JSON import to overwrite everybody’s progress.

Earlier browser-only progress

If you used the earlier local version, your old progress remains on that browser. Export earlier local progress backs it up separately. Review and re-enter any changes you want to share; old local records never silently replace the team's current work.

If a stale page still says Saved on this browser, export that copy and reload the website before collaborating.

Files & document links

Open a task and find Files & links:

  • Upload file: choose a deck, image, PDF or other file up to 10 MiB. Wait for “Uploaded and attached to the shared task.” The attachment is saved immediately, separately from other unsaved task fields.
  • Download: click an attachment’s filename. Decks download as files; an online PowerPoint link is better if you want teammates to open it in the browser.
  • Add link: enter a title and a full HTTPS URL, click Add link, then Save changes. Links are not saved until the task is saved.
  • Larger files: use a PowerPoint/OneDrive, Google Drive, Canva or other online link. Set viewing permissions so teammates can open it. The 10 MiB limit is this website’s upload limit.

Use a named link in Files & links so teammates can find the document. Adding a link does not grant access to a private document; check its sharing permissions.

Team activity & editing conflicts

Team activity shows up to 200 recent updates and 200 sign-ins, including the supplied name and time. The shared password does not verify a person’s identity; names are self-reported. Browser-local mode does not record a shared visitor or completion history.

If someone changes a task while you are editing it, saving shows a conflict and keeps your draft open. Copy your unsaved text before using Reload shared task, because reloading discards the form’s unsaved fields after confirmation. Reapply your changes to the latest version and save again.

Common questions

Why can’t someone else see my checkmarks?

Wait for Saved to GitHub, then ask your teammate to click Refresh. If either browser still shows Saved on this browser, export its old local progress and reload the website.

Why is there no upload button?

Sign in with your name and password, then open a task. Files & links appears in the task editor. If you are viewing an older cached page, reload the website.

What if a save or upload fails?

Do not assume it succeeded. Keep the form open and copy your unsaved notes. In shared mode, refresh and check the current task and attachment list before retrying an upload; a network error can occur after a save reached the server.

Can I leave the board safely?

Finish saving first, then use Lock or Lock workspace. You will need the workspace password again. Locking keeps saved progress; it does not delete it. Export important local progress before clearing browser data.
